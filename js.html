تعلم JavaScript من الصفر

تعلم JavaScript خطوة بخطوة، من المتغيرات والشروط والحلقات إلى الدوال والمصفوفات وDOM والأحداث والبرمجة غير المتزامنة وبناء المشاريع.

01

ما هي JavaScript؟

JavaScript لغة برمجة تضيف التفاعل والسلوك إلى صفحات الويب. يمكنك بها الاستجابة للنقرات، وتغيير المحتوى، والتحقق من النماذج، والتعامل مع البيانات.

HTML تبني الهيكل، وCSS تنسّق المظهر، وJavaScript تضيف السلوك والتفاعل.
02

كيف تعمل JavaScript في المتصفح؟

ينفذ المتصفح كود JavaScript عبر محرك JavaScript. يمكن للكود التعامل مع الصفحة من خلال DOM والاستجابة لأحداث المستخدم.

يمكن تشغيل JavaScript داخل المتصفح أو خارج المتصفح باستخدام بيئات مثل Node.js.
03

إضافة JavaScript إلى HTML

يمكن كتابة JavaScript داخل وسم script أو ربط ملف خارجي باستخدام src. غالبًا الأفضل وضع الملف الخارجي مع defer.

index.html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>JavaScript</title>
  <script src="script.js" defer></script>
</head>
<body>
  <h1>مرحباً</h1>
</body>
</html>
defer يجعل المتصفح ينفذ الملف بعد تحليل HTML.
04

أول أمر: console.log

تستخدم console.log() لعرض القيم والرسائل في وحدة التحكم، وهي أداة أساسية لفهم ما يحدث أثناء تنفيذ البرنامج.

script.js
console.log("Hello JavaScript!");
console.log(10 + 5);
console.log("MA Academy");
افتح أدوات المطور في المتصفح ثم Console لرؤية النتيجة.
05

التعليقات Comments

التعليقات نصوص لا ينفذها JavaScript. استخدم // للتعليق في سطر واحد و/* */ للتعليق متعدد الأسطر.

comments.js
// تعليق في سطر واحد

/*
  تعليق متعدد الأسطر
*/

console.log("Start learning");
اكتب تعليقات تشرح السبب أو الفكرة، لا ما يظهر بوضوح من الكود.
06

المتغيرات: let وconst

تستخدم let لتعريف متغير يمكن إعادة إسناد قيمته، بينما const لتعريف مرجع لا يمكن إعادة إسناده. تجنب var في الشيفرات الحديثة غالبًا.

variables.js
const academy = "MA Academy";
let score = 10;

score = 15;

console.log(academy);
console.log(score);
استخدم const افتراضيًا، وانتقل إلى let عندما تحتاج إلى إعادة الإسناد.
07

قواعد تسمية المتغيرات

يمكن أن تحتوي أسماء المتغيرات على حروف وأرقام و_ و$، لكن لا تبدأ برقم ولا تستخدم الكلمات المحجوزة. JavaScript حساسة لحالة الأحرف.

names.js
let studentName = "Ali";
let studentAge = 19;
let isLearning = true;

console.log(studentName, studentAge, isLearning);
اختر أسماء واضحة مثل studentName بدل x عندما يكون ذلك ممكنًا.
08

أنواع البيانات Data Types

تشمل الأنواع الأساسية String وNumber وBoolean وUndefined وNull وBigInt وSymbol، كما أن Object يشمل الكائنات والمصفوفات والدوال.

types.js
let name = "Sara";       // string
let age = 20;             // number
let active = true;        // boolean
let result;               // undefined
let selected = null;       // null

console.log(typeof name);
console.log(typeof age);
console.log(typeof active);
استخدم typeof لفحص نوع قيمة في حالات كثيرة.
09

الأرقام والعمليات الحسابية

تدعم JavaScript الجمع والطرح والضرب والقسمة وباقي القسمة والأس، باستخدام + و- و* و/ و% و**.

math.js
let a = 12;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** 2);
عامل + يمكن أن يجمع الأرقام أو يدمج النصوص حسب نوع القيم.
10

النصوص Strings

يمكن كتابة النصوص بين علامات اقتباس مفردة أو مزدوجة أو backticks. النصوص تدعم خصائص ودوال كثيرة لمعالجتها.

strings.js
const name = "Mouattassim";
const course = "JavaScript";

console.log(`Welcome ${name}`);
console.log(course.length);
console.log(course.toUpperCase());
console.log(course.toLowerCase());
استخدم template literals لإدراج المتغيرات داخل النص بسهولة.
11

دمج النصوص وTemplate Literals

يمكن دمج النصوص باستخدام + أو كتابة تعبيرات داخل ${} بين علامتي backtick. الطريقة الثانية أوضح عند بناء جمل مركبة.

template.js
const firstName = "Ali";
const age = 18;

const message = `My name is ${firstName} and I am ${age}.`;
console.log(message);
تسمى الصيغة التي تستخدم backticks بالقوالب النصية Template Literals.
12

تحويل أنواع البيانات

تستطيع تحويل النص إلى رقم باستخدام Number() أو parseInt() أو parseFloat()، وتحويل القيم إلى نص باستخدام String().

conversion.js
const textNumber = "25";

const number = Number(textNumber);
const message = String(number);

console.log(number + 5);
console.log(message);
console.log(Number("hello")); // NaN
تحقق من نتيجة التحويل، فقد تحصل على NaN إذا تعذر تحويل النص إلى رقم.
13

المقارنات Comparison

تنتج المقارنات قيمة Boolean مثل أكبر من وأصغر من والمساواة. يفضّل استخدام === و!== للمقارنة الصارمة دون تحويل نوع تلقائي.

comparison.js
console.log(10 > 5);
console.log(10 === "10"); // false
console.log(10 == "10");  // true
console.log(7 !== 3);
الفرق الأساسي: == تسمح بتحويل الأنواع، أما === فتقارن القيمة والنوع.
14

العوامل المنطقية

تستخدم && بمعنى AND و|| بمعنى OR و! بمعنى NOT لدمج الشروط أو عكس قيمتها المنطقية.

logical.js
const age = 20;
const hasCard = true;

console.log(age >= 18 && hasCard);
console.log(age < 18 || hasCard);
console.log(!hasCard);
تستخدم هذه العوامل كثيرًا داخل if وعند التحقق من أكثر من شرط.
15

الشروط if وelse

تسمح if بتنفيذ كود عند تحقق شرط، ويمكن إضافة else لتنفيذ مسار بديل وelse if لاختبار شروط إضافية.

conditions.js
const grade = 14;

if (grade >= 16) {
  console.log("Excellent");
} else if (grade >= 10) {
  console.log("Passed");
} else {
  console.log("Try again");
}
رتّب الشروط من الأكثر تحديدًا إلى الأكثر عمومية عند الحاجة.
16

Switch وCase

تستخدم switch لمقارنة قيمة واحدة بعدة حالات. أضف break لمنع الانتقال إلى الحالة التالية، ويمكن استخدام default للحالة الافتراضية.

switch.js
const day = 2;

switch (day) {
  case 1:
    console.log("Sunday");
    break;
  case 2:
    console.log("Monday");
    break;
  default:
    console.log("Unknown day");
}
يمكن جمع أكثر من case لتنفيذ نفس التعليمات.
17

العامل Ternary

العامل الشرطي المختصر يكتب بالشكل condition ? value1 : value2، ويكون مفيدًا للتعبيرات البسيطة.

ternary.js
const age = 19;

const status = age >= 18
  ? "Adult"
  : "Minor";

console.log(status);
لا تستخدمه عندما يجعل الشروط المعقدة صعبة القراءة.
18

حلقة for

تكرر for تنفيذ كتلة من التعليمات، وتتكون عادة من بداية العداد والشرط والتحديث.

for.js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
انتبه إلى تحديث العداد حتى لا تنشئ حلقة لا نهائية.
19

حلقة while

تستمر while في التكرار ما دام الشرط صحيحًا. يجب تغيير الحالة داخل الحلقة حتى لا تستمر إلى ما لا نهاية.

while.js
let count = 1;

while (count <= 5) {
  console.log(count);
  count++;
}
استخدمها عندما لا تعرف مسبقًا عدد مرات التكرار.
20

حلقة do...while

تنفذ do...while الكتلة مرة واحدة على الأقل، ثم تتحقق من الشرط لتقرر تكرارها.

do-while.js
let number = 1;

do {
  console.log(number);
  number++;
} while (number <= 3);
تختلف عن while في أن فحص الشرط يأتي بعد التنفيذ الأول.
21

break وcontinue

توقف break الحلقة أو switch، بينما تتجاوز continue الدورة الحالية وتنتقل إلى الدورة التالية.

break-continue.js
for (let i = 1; i <= 6; i++) {
  if (i === 3) continue;
  if (i === 5) break;

  console.log(i);
}
استخدمهما عندما يجعلان منطق الحلقة أوضح.
22

الدوال Functions

الدالة كتلة قابلة لإعادة الاستخدام، تنفذ عند استدعائها. يمكنها استقبال معاملات وإرجاع نتيجة باستخدام return.

functions.js
function greet(name) {
  return `Hello ${name}`;
}

const message = greet("Ali");
console.log(message);
قسّم البرنامج إلى دوال صغيرة لكل منها مسؤولية واضحة.
23

Function Expression

يمكن تخزين دالة داخل متغير، وتسمى هذه الطريقة Function Expression. يمكن أن تكون الدالة مجهولة الاسم.

expression.js
const add = function(a, b) {
  return a + b;
};

console.log(add(4, 6));
الدوال المعرفة بهذه الطريقة لا تتصرف مثل function declarations في الرفع Hoisting.
24

Arrow Functions

توفر Arrow Functions صياغة مختصرة للدوال باستخدام السهم =>. وهي شائعة في callbacks ومعالجة المصفوفات.

arrow.js
const multiply = (a, b) => {
  return a * b;
};

const square = n => n * n;

console.log(multiply(3, 4));
console.log(square(5));
لها سلوك مختلف عن الدوال العادية في this.
25

المعاملات والقيم الافتراضية

يمكن للدالة استقبال عدة معاملات، ويمكن وضع قيمة افتراضية للمعامل إذا لم يرسل المستدعي قيمة له.

parameters.js
function welcome(name = "Guest") {
  return `Welcome ${name}`;
}

console.log(welcome("Sara"));
console.log(welcome());
تُستخدم القيم الافتراضية لتجنب التعامل مع undefined في كثير من الحالات.
26

النطاق Scope

يحدد Scope المكان الذي يمكن منه الوصول إلى المتغير. من أنواعه Global Scope وFunction Scope وBlock Scope.

scope.js
const globalName = "MA";

function showName() {
  const localName = "Academy";
  console.log(globalName, localName);
}

showName();
// localName غير متاح هنا
let وconst لهما نطاق كتلي، بينما var له نطاق الدالة أو النطاق العام.
27

Hoisting

Hoisting هو سلوك في JavaScript يتعلق بكيفية معالجة تعريفات المتغيرات والدوال قبل تنفيذ الكود. تختلف التفاصيل بين var وlet وconst والدوال.

hoisting.js
sayHello();

function sayHello() {
  console.log("Hello!");
}

// let وconst لا يمكن استعمالهما
// قبل سطر التعريف بسبب TDZ
لا تعتمد على Hoisting لتكتب كودًا مربكًا؛ عرّف المتغيرات قبل استخدامها.
28

المصفوفات Arrays

المصفوفة تخزن مجموعة قيم مرتبة داخل متغير واحد. يبدأ الفهرس من 0، ويمكن الوصول إلى العنصر باستخدام index.

arrays.js
const fruits = ["Apple", "Orange", "Banana"];

console.log(fruits[0]);
console.log(fruits[2]);
console.log(fruits.length);
استخدم length لمعرفة عدد العناصر.
29

إضافة وحذف عناصر المصفوفة

تسمح push وpop بالتعديل في نهاية المصفوفة، بينما unshift وshift تعدلان بدايتها.

array-methods.js
const numbers = [10, 20];

numbers.push(30);
numbers.unshift(5);

numbers.pop();
numbers.shift();

console.log(numbers);
هذه الدوال تعدّل المصفوفة الأصلية.
30

slice وsplice

تعيد slice جزءًا من المصفوفة دون تعديل الأصل، بينما splice يمكنها حذف أو إضافة عناصر داخل المصفوفة الأصلية.

slice-splice.js
const items = ["a", "b", "c", "d"];

const part = items.slice(1, 3);
items.splice(1, 1, "new");

console.log(part);
console.log(items);
تذكر: slice لا تعدّل الأصل، وsplice تعدّله.
31

for...of وforEach

تستخدم for...of للتكرار على قيم العناصر القابلة للتكرار، بينما forEach تنفذ دالة لكل عنصر في المصفوفة.

iteration.js
const names = ["Ali", "Sara", "Lina"];

for (const name of names) {
  console.log(name);
}

names.forEach((name, index) => {
  console.log(index, name);
});
for...of تدعم break وcontinue، أما forEach فلا تستخدم معها break بالطريقة نفسها.
32

map وfilter وreduce

map تنشئ مصفوفة جديدة من نتائج تحويل العناصر، وfilter تختار العناصر المطابقة لشرط، وreduce تجمع القيم في نتيجة واحدة.

array-functional.js
const numbers = [1, 2, 3, 4];

const doubled = numbers.map(n => n * 2);
const even = numbers.filter(n => n % 2 === 0);
const total = numbers.reduce((sum, n) => sum + n, 0);

console.log(doubled, even, total);
هذه الدوال لا تعدّل المصفوفة الأصلية بحد ذاتها.
33

الكائنات Objects

الكائن يخزن البيانات على شكل خصائص وقيم، ويمكن الوصول إلى الخاصية باستخدام النقطة أو الأقواس.

objects.js
const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

console.log(student.name);
console.log(student["age"]);
تسمى البيانات داخل الكائن properties، والدوال داخله methods.
34

إضافة وتعديل وحذف خصائص

يمكن إنشاء خاصية جديدة أو تعديل قيمة موجودة أو حذف خاصية باستخدام delete.

object-properties.js
const user = { name: "Sara" };

user.age = 19;
user.name = "Lina";
delete user.age;

console.log(user);
يمكن الوصول إلى الخاصية ديناميكيًا باستخدام الأقواس المربعة.
35

Destructuring

يسمح Destructuring باستخراج قيم من المصفوفات أو خصائص من الكائنات إلى متغيرات بطريقة مختصرة.

destructuring.js
const user = {
  name: "Ali",
  age: 21
};

const { name, age } = user;

const colors = ["red", "blue"];
const [first, second] = colors;

console.log(name, age, first, second);
يمكن استخدام قيم افتراضية عند غياب الخاصية أو العنصر.
36

Spread وRest

يستخدم Spread operator (...) لفرد عناصر مصفوفة أو خصائص كائن، بينما Rest يجمع عدة قيم في مصفوفة أو كائن.

spread-rest.js
const first = [1, 2];
const all = [...first, 3, 4];

function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}

console.log(all);
console.log(sum(1, 2, 3));
تتحدد وظيفة ... من موضع استخدامها.
37

Set وMap

Set مجموعة تحفظ قيمًا فريدة، بينما Map تخزن أزواجًا من المفاتيح والقيم ويمكن أن تكون المفاتيح من أنواع مختلفة.

set-map.js
const unique = new Set([1, 2, 2, 3]);
unique.add(4);

const scores = new Map();
scores.set("Ali", 18);
scores.set("Sara", 20);

console.log([...unique]);
console.log(scores.get("Sara"));
استخدم Set لإزالة التكرار، وMap عندما تحتاج إلى خريطة مفاتيح وقيم مرنة.
38

DOM: الوصول إلى العناصر

DOM هو تمثيل الصفحة كعقد يمكن لـ JavaScript قراءتها وتعديلها. استخدم getElementById أو querySelector للوصول إلى العناصر.

dom.js
const title = document.getElementById("title");
const firstButton = document.querySelector(".btn");
const allCards = document.querySelectorAll(".card");

console.log(title, firstButton, allCards);
querySelector يعيد أول عنصر يطابق المحدد، وquerySelectorAll يعيد مجموعة عناصر.
39

تغيير النص والمحتوى

يمكن تغيير النص باستخدام textContent، وتغيير HTML الداخلي باستخدام innerHTML. استخدم textContent للنصوص غير الموثوقة.

dom-content.js
const title = document.querySelector("h1");

title.textContent = "Welcome to MA Academy";

// استخدم innerHTML فقط مع HTML موثوق
// title.innerHTML = "<strong>Welcome</strong>";
إدخال بيانات غير موثوقة عبر innerHTML قد يسبب ثغرات XSS.
40

تغيير CSS وClasses عبر JavaScript

يمكن تغيير style مباشرة أو استخدام classList لإضافة وإزالة وتبديل classes. يفضّل غالبًا إدارة المظهر عبر CSS classes.

dom-style.js
const card = document.querySelector(".card");

card.classList.add("active");
card.classList.remove("hidden");
card.classList.toggle("selected");

// تعديل مباشر عند الحاجة
card.style.borderRadius = "12px";
classList.add وremove وtoggle أدوات مهمة للتفاعل مع التصميم.
41

إنشاء وإزالة عناصر DOM

يمكن إنشاء عنصر باستخدام createElement، ثم إضافة محتوى إليه وإلحاقه بالصفحة باستخدام append أو appendChild.

create-elements.js
const item = document.createElement("li");
item.textContent = "New lesson";

document.querySelector("ul").append(item);

// لاحقًا:
item.remove();
استخدم remove لحذف العنصر من الصفحة.
42

الأحداث Events

الأحداث تمثل تفاعلات المستخدم أو المتصفح مثل click وinput وsubmit وkeydown. اربط الحدث باستخدام addEventListener.

events.js
const button = document.querySelector("button");

button.addEventListener("click", () => {
  console.log("Button clicked!");
});
ضع اسم الحدث دون كلمة on، مثل click وليس onclick.
43

Event Object وpreventDefault

تستقبل دالة الحدث كائنًا يحتوي معلومات عن الحدث والعنصر المستهدف. preventDefault يمنع السلوك الافتراضي عند الحاجة.

event-object.js
document.querySelector("form")
  .addEventListener("submit", event => {
    event.preventDefault();
    console.log(event.target);
  });
في إرسال النماذج، يمنع preventDefault إعادة تحميل الصفحة تلقائيًا.
44

النماذج وقراءة المدخلات

يمكن قراءة قيمة input عبر value، ثم التحقق منها قبل استخدامها. تعامل مع المدخلات باعتبارها بيانات تحتاج إلى تحقق.

forms.js
const input = document.querySelector("#name");
const button = document.querySelector("#send");

button.addEventListener("click", () => {
  const name = input.value.trim();
  console.log(name);
});
تحقق من البيانات في الواجهة والخادم؛ تحقق المتصفح وحده لا يكفي للأمان.
45

JSON

JSON صيغة نصية لتبادل البيانات. تستخدم JSON.stringify لتحويل قيمة JavaScript إلى نص JSON، وJSON.parse لتحويل النص إلى قيمة.

json.js
const user = {
  name: "Sara",
  age: 20
};

const text = JSON.stringify(user);
const object = JSON.parse(text);

console.log(text);
console.log(object.name);
النص غير الصحيح في JSON.parse يؤدي إلى خطأ؛ يمكن استخدام try...catch.
46

التعامل مع الأخطاء try...catch

يسمح try...catch بالتعامل مع الأخطاء أثناء التنفيذ بدل توقف المسار دون معالجة. يمكن استخدام finally لتنفيذ تعليمات في النهاية.

errors.js
try {
  const data = JSON.parse("{bad json}");
  console.log(data);
} catch (error) {
  console.error("حدث خطأ:", error.message);
} finally {
  console.log("انتهت العملية");
}
استخدم catch لمعالجة الخطأ أو إظهار رسالة مفيدة، ولا تبتلع الأخطاء بصمت.
47

البرمجة غير المتزامنة

بعض العمليات تستغرق وقتًا مثل طلب البيانات أو المؤقتات. JavaScript توفر callbacks وPromises وasync/await للتعامل معها.

async.js
console.log("First");

setTimeout(() => {
  console.log("After 1 second");
}, 1000);

console.log("Last");
فهم الفرق بين المتزامن وغير المتزامن أساس مهم عند بناء التطبيقات.
48

setTimeout وsetInterval

ينفذ setTimeout دالة مرة واحدة بعد مدة، بينما setInterval يكرر تنفيذها بفاصل زمني. يمكن إيقافهما باستخدام clearTimeout وclearInterval.

timers.js
const timeoutId = setTimeout(() => {
  console.log("Hello");
}, 1000);

const intervalId = setInterval(() => {
  console.log("Tick");
}, 2000);

// إيقاف التكرار:
// clearInterval(intervalId);
المدة تقاس بالميلي ثانية، و1000 ميلي ثانية تساوي ثانية واحدة.
49

Promises

Promise تمثل نتيجة عملية غير متزامنة قد تكون pending أو fulfilled أو rejected. يمكن التعامل معها عبر then وcatch وfinally.

promises.js
const task = new Promise((resolve, reject) => {
  resolve("Done!");
});

task
  .then(result => console.log(result))
  .catch(error => console.error(error))
  .finally(() => console.log("Finished"));
تساعد Promises على تنظيم العمليات غير المتزامنة وتجنب تداخل callbacks.
50

async وawait

تسمح async وawait بكتابة الشيفرات المعتمدة على Promises بأسلوب أقرب إلى التنفيذ المتسلسل. الدالة async تعيد Promise دائمًا.

async-await.js
function getMessage() {
  return Promise.resolve("Hello!");
}

async function showMessage() {
  try {
    const message = await getMessage();
    console.log(message);
  } catch (error) {
    console.error(error);
  }
}

showMessage();
استخدم try...catch لمعالجة الأخطاء عند await.
51

Fetch API

تستخدم fetch لإرسال طلبات HTTP والحصول على Response. غالبًا نقرأ البيانات بصيغة JSON باستخدام response.json().

fetch.js
async function loadUsers() {
  const response = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );

  if (!response.ok) {
    throw new Error("Request failed");
  }

  const users = await response.json();
  console.log(users);
}

loadUsers().catch(console.error);
تحقق من response.ok لأن fetch لا ترفض Promise تلقائيًا عند كل حالات HTTP مثل 404.
52

Modules: import وexport

تسمح Modules بتقسيم البرنامج إلى ملفات مستقلة. استخدم export لإتاحة قيم من ملف وimport لاستيرادها في ملف آخر.

math.js
// math.js
export function add(a, b) {
  return a + b;
}

// main.js
import { add } from "./math.js";
console.log(add(2, 3));
في HTML استخدم script type="module" لتشغيل ملف JavaScript كوحدة.
53

التخزين المحلي localStorage

يتيح localStorage حفظ بيانات نصية في المتصفح لتبقى بعد إغلاق الصفحة. استخدم setItem وgetItem وremoveItem.

storage.js
localStorage.setItem("theme", "dark");

const theme = localStorage.getItem("theme");
console.log(theme);

// حذف قيمة:
// localStorage.removeItem("theme");
للتعامل مع كائنات ومصفوفات، حوّلها إلى JSON قبل التخزين.

التعامل مع التاريخ والوقت

يوفر كائن Date أدوات لإنشاء التواريخ وقراءة اليوم والشهر والسنة والوقت. انتبه إلى أن getMonth يبدأ من 0.

date.js
const now = new Date();

console.log(now.getFullYear());
console.log(now.getMonth() + 1);
console.log(now.getDate());

console.log(
  new Intl.DateTimeFormat("ar").format(now)
);
يمكن استخدام Intl.DateTimeFormat لعرض التاريخ وفق اللغة والمنطقة.
55

الأرقام وMath

يوفر Math دوالًا مثل round وfloor وceil وrandom وmax وmin وsqrt لتنفيذ عمليات رياضية.

math-object.js
console.log(Math.round(4.6));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
console.log(Math.max(3, 9, 5));
console.log(Math.sqrt(81));

const random = Math.random();
console.log(random);
Math.random تعطي قيمة عشوائية أكبر من أو تساوي 0 وأقل من 1.

مقدمة إلى OOP والكلاسات

البرمجة كائنية التوجه تنظم الكود حول الكائنات. تتيح class تعريف قالب لإنشاء كائنات ذات خصائص ودوال.

class.js
class Student {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  introduce() {
    console.log(`I am ${this.name}`);
  }
}

const student = new Student("Ali", 20);
student.introduce();
الكلاسات في JavaScript مبنية على نموذج prototype.
57

الوراثة Inheritance

تسمح extends بإنشاء class يرث من class آخر، ويستخدم super لاستدعاء constructor الأب أو دواله.

inheritance.js
class Person {
  constructor(name) {
    this.name = name;
  }
}

class Student extends Person {
  constructor(name, course) {
    super(name);
    this.course = course;
  }
}

const s = new Student("Sara", "JS");
console.log(s.name, s.course);
استخدم الوراثة عندما توجد علاقة واضحة بين النوع العام والنوع المتخصص.
58

this وطرق الكائن

تشير this إلى سياق الاستدعاء في الدوال العادية، وقد يختلف معناها حسب طريقة استدعاء الدالة. Arrow functions لا تنشئ this خاصة بها.

this.js
const user = {
  name: "Ali",
  sayName() {
    console.log(this.name);
  }
};

user.sayName();
لا تفترض أن this تشير دائمًا إلى الكائن الذي كُتبت الدالة داخله.

التعبيرات النمطية RegExp

تستخدم Regular Expressions للبحث عن أنماط داخل النصوص والتحقق من صيغ معينة. يمكن إنشاؤها بين / / أو باستخدام RegExp.

regex.js
const email = "student@example.com";
const pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

console.log(pattern.test(email));
التعبير النمطي أداة مساعدة للتحقق، لكنه لا يغني عن التحقق الكامل من البيانات.

مشروع تطبيقي: قائمة مهام

طبّق DOM والأحداث والمصفوفات لإنشاء قائمة مهام. أدخل مهمة، أضفها إلى القائمة، واسمح بحذفها عند الضغط عليها.

todo.html
<!-- HTML -->
<input id="taskInput" placeholder="مهمة جديدة">
<button id="addTask">إضافة</button>
<ul id="tasks"></ul>

<script>
const input = document.querySelector("#taskInput");
const button = document.querySelector("#addTask");
const list = document.querySelector("#tasks");

button.addEventListener("click", () => {
  const value = input.value.trim();
  if (!value) return;

  const item = document.createElement("li");
  item.textContent = value;
  item.addEventListener("click", () => item.remove());

  list.append(item);
  input.value = "";
});
</script>
ابدأ بهذا المثال ثم أضف حفظ المهام في localStorage.
لا توجد دروس مطابقة لبحثك.
