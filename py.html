تعلم لغة Python

دليلك الشامل لتعلم أساسيات لغة Python من الصفر إلى الاحتراف.

مقدمة عن Python

Python هي لغة برمجة عالية المستوى وسهلة التعلم، تُستخدم في تطوير التطبيقات والمواقع وتحليل البيانات والذكاء الاصطناعي والتعلم الآلي. تتميز ببساطة قواعد كتابتها وقوة مكتباتها.

01 - أساسيات اللغة

Print

1. أمر الطباعة print()

يُستخدم الأمر print() لعرض النصوص أو القيم أو نتائج العمليات على شاشة الإخراج. 

print("Hello World")
print(25)
print(10 + 5)
النتيجة: Hello World ثم 25 ثم 15.
Variables

2. المتغيرات Variables

المتغير هو اسم نستخدمه لتخزين قيمة معينة داخل الذاكرة، ويمكن تغيير قيمته أثناء تنفيذ البرنامج. 

name = "Ahmed"
age = 20
price = 15.5

print(name)
print(age)
Data Types

3. أنواع البيانات Data Types

تحدد نوع القيمة التي يتعامل معها البرنامج.

name = "Python"   # str
age = 20          # int
price = 12.5      # float
is_active = True  # boolprint(type(name))
print(type(age))
print(type(price))
str: نصوص - int: أعداد صحيحة - float: أعداد عشرية - bool: قيم منطقية.
Input

4. إدخال البيانات input()

يُستخدم input() لاستقبال البيانات من المستخدم أثناء تشغيل البرنامج. وتكون القيمة المستقبلة نصاً افتراضياً. 

name = input("Enter your name: ")
print("Welcome", name)

age = int(input("Enter your age: "))
print(age)
Comments

5. التعليقات Comments

تُستخدم التعليقات لكتابة ملاحظات توضيحية داخل الكود، ولا ينفذها المفسر. 

# This is a comment

print("Hello")

02 - العمليات Operators

6. العمليات الحسابية Arithmetic Operators

تُستخدم لتنفيذ العمليات الرياضية.

a = 10
b = 3

print(a + b)  # Addition
print(a - b)  # Subtraction
print(a * b)  # Multiplication
print(a / b)  # Division
print(a // b) # Floor division
print(a % b)  # Modulo
print(a ** b) # Power

7. عمليات المقارنة Comparison Operators

تُستخدم لمقارنة قيمتين وتُرجع True أو False.

a = 10
b = 5

print(a == b)
print(a != b)
print(a > b)
print(a < b)
print(a >= b)
print(a <= b)

8. العمليات المنطقية Logical Operators

تُستخدم لربط الشروط والتحقق منها.

age = 20

print(age > 18 and age < 30)
print(age < 18 or age > 60)
print(not age > 18)
and: يجب تحقق الشرطين - or: يكفي تحقق أحدهما - not: عكس النتيجة.

03 - الشروط Conditions

9. شرط if

يُستخدم لتنفيذ مجموعة أوامر عندما يكون الشرط صحيحاً.

age = 20

if age >= 18:
    print("Adult")

10. الشرطان elif و else

elif يُستخدم لاختبار شرط إضافي، بينما else يُنفذ عندما لا يتحقق أي شرط سابق. 

mark = 15

if mark >= 16:
    print("Excellent")

elif mark >= 10:
    print("Passed")

else:
    print("Failed")

11. Match Case

يُستخدم لمقارنة قيمة مع عدة حالات محتملة.

day = 2

match day:
    case 1:
        print("Sunday")
    case 2:
        print("Monday")
    case _:
        print("Unknown day")
يتوفر match/case ابتداءً من Python 3.10.

04 - الحلقات التكرارية Loops

12. حلقة for

تُستخدم لتكرار الأوامر على عناصر مجموعة أو ضمن نطاق محدد.

for i in range(5):
    print(i)
النتيجة: 0 1 2 3 4

13. حلقة while

تكرر الأوامر ما دام الشرط صحيحاً.

i = 1

while i <= 5:
    print(i)
    i += 1

14. أمر break

يوقف الحلقة التكرارية مباشرة.

for i in range(10):
    if i == 5:
        break
    print(i)

15. أمر continue

يتجاوز التكرار الحالي وينتقل إلى التكرار التالي.

for i in range(5):
    if i == 2:
        continue
    print(i)

16. أمر pass

يُستخدم كتعليمة فارغة عندما نحتاج إلى ترك مكان للكود لاحقاً.

for i in range(5):
    if i == 2:
        pass
    print(i)

05 - هياكل البيانات Data Structures

17. القوائم Lists

تُستخدم لتخزين عدة عناصر في متغير واحد، ويمكن تعديل عناصرها وإضافة عناصر جديدة. 

students = ["Ali", "Sara", "Omar"]

print(students[0])

students.append("Ahmed")
students.remove("Sara")

print(students)

18. الصفوف Tuples

تشبه القوائم لكنها غير قابلة للتعديل بعد إنشائها. 

numbers = (10, 20, 30)

print(numbers[0])
print(len(numbers))

19. المجموعات Sets

تُستخدم لتخزين عناصر غير مكررة، ولا تعتمد على ترتيب ثابت للعناصر. 

numbers = {1, 2, 3, 3, 4}

numbers.add(5)
numbers.remove(2)

print(numbers)

20. القواميس Dictionaries

تخزن البيانات على شكل مفتاح وقيمة Key : Value. 

student = {
    "name": "Ali",
    "age": 20,
    "grade": 15
}

print(student["name"])

student["age"] = 21
student["city"] = "Algeria"

06 - الدوال Functions

21. إنشاء الدوال def

تُستخدم def لتعريف دالة تحتوي على مجموعة من الأوامر يمكن استدعاؤها عدة مرات. 

def greet():
    print("Welcome to Python")

greet()

22. Parameters و Arguments

Parameters هي المتغيرات التي تستقبلها الدالة، وArguments هي القيم التي نمررها عند استدعائها. 

def greet(name):
    print("Hello", name)

greet("Ahmed")

23. return

تُستخدم لإرجاع نتيجة من الدالة إلى المكان الذي استدعاها.

def add(a, b):
    return a + b

result = add(10, 5)

print(result)

24. Lambda

تُستخدم لإنشاء دوال صغيرة ومختصرة دون الحاجة إلى كتابة def. 

square = lambda x: x * x

print(square(5))

07 - التعامل مع النصوص Strings

25. خصائص النصوص

تحتوي Python على دوال عديدة لمعالجة النصوص.

text = "hello python"

print(text.upper())
print(text.lower())
print(text.capitalize())
print(text.title())
print(len(text))

26. تقسيم واستبدال النصوص

text = "I love Python"

print(text.replace("Python", "Programming"))

words = text.split()
print(words)

27. تنسيق النصوص f-string

تسمح بإدخال قيم المتغيرات داخل النصوص بطريقة سهلة.

name = "Ahmed"
age = 20

print(f"My name is {name} and I am {age}")

08 - الملفات والأخطاء

28. التعامل مع الملفات open()

تُستخدم لفتح الملفات وقراءتها أو الكتابة فيها.

# Writing
with open("test.txt", "w") as file:
    file.write("Hello Python")

# Reading
with open("test.txt", "r") as file:
    content = file.read()

print(content)
r: القراءة - w: الكتابة مع استبدال المحتوى - a: الإضافة.

29. معالجة الأخطاء try و except

تسمح بالتعامل مع الأخطاء دون إيقاف البرنامج بشكل غير متحكم فيه.

try:
    number = int(input("Enter a number: "))
    print(10 / number)

except ValueError:
    print("Invalid number")

except ZeroDivisionError:
    print("Cannot divide by zero")

09 - البرمجة الكائنية OOP

30. Classes و Objects

Class هو قالب لإنشاء الكائنات، أما Object فهو نسخة من هذا القالب تحتوي على بيانات وسلوكيات. 

class Student:

    def init(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(self.name, self.age)

student1 = Student("Ali", 20)

student1.introduce()

10 - أهم المكتبات Libraries

31. NumPy

مكتبة تُستخدم في العمليات الحسابية والعلمية والتعامل مع المصفوفات متعددة الأبعاد. 

import numpy as np

numbers = np.array([10, 20, 30, 40])

print(np.max(numbers))
print(np.min(numbers))
print(np.mean(numbers))
print(np.sum(numbers))

32. Pandas

مكتبة قوية لمعالجة البيانات وتنظيمها وتحليلها باستخدام الجداول DataFrames. 

import pandas as pd

data = {
    "Name": ["Ali", "Sara", "Omar"],
    "Age": [20, 21, 22]
}

df = pd.DataFrame(data)

print(df)
print(df.head())
print(df.describe())

33. Matplotlib

مكتبة تُستخدم لإنشاء الرسوم البيانية وتمثيل البيانات بصرياً. 

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 15, 30]

plt.plot(x, y)

plt.title("My First Graph")
plt.xlabel("X")
plt.ylabel("Y")

plt.show()
