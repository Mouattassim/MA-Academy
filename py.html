المعاملات *args و **kwargs

البرمجة كائنية التوجه OOP

الوراثة Inheritance

المولدات Generators

تنتج generator القيم عند الحاجة باستخدام yield بدل إنشاء كل النتائج دفعة واحدة في الذاكرة.

generators.py
def count_up_to(limit):
    number = 1
    while number <= limit:
        yield number
        number += 1

for value in count_up_to(3):
    print(value)

    result = num1 + num2
