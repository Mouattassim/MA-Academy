تعلم HTML

تعلم لغة HTML واكتشف كيفية بناء صفحات الويب وتنظيم المحتوى باستخدام أهم الوسوم والعناصر.

ما هي HTML؟

HTML هي لغة ترميز النص التشعبي (HyperText Markup Language)، وتُستخدم لإنشاء هيكل صفحات الويب وتنظيم محتواها، مثل العناوين والفقرات والصور والروابط والجداول والنماذج.

01 - الهيكل الأساسي

DOCTYPE

1. تصريح DOCTYPE

يُكتب في بداية مستند HTML لإعلام المتصفح بأن الصفحة تستخدم معيار HTML5. 

<!DOCTYPE html>
html

2. وسم HTML

يمثل العنصر الجذر للمستند، ويحتوي على جميع عناصر الصفحة. 

<html lang="ar">

</html>
head

3. وسم HEAD

يحتوي على المعلومات الوصفية للصفحة، مثل العنوان وربط ملفات CSS وتحديد الترميز. 

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>
body

4. وسم BODY

يحتوي على جميع العناصر والمحتويات التي تظهر للمستخدم داخل صفحة الويب. 

<body>
    <h1>Welcome</h1>
    <p>Hello World</p>
</body>

02 - النصوص والعناوين

5. العناوين Headings

تُستخدم العناوين لتنظيم محتوى الصفحة، وتتدرج من h1 وهو العنوان الأكثر أهمية إلى h6. 

<h1>Main Title</h1>
<h2>Second Title</h2>
<h3>Third Title</h3>
<h4>Title 4</h4>
<h5>Title 5</h5>
<h6>Title 6</h6>

6. الفقرات Paragraphs

يُستخدم وسم p لإنشاء فقرة نصية.

<p>This is a paragraph.</p>

7. كسر السطر br

يُستخدم للانتقال إلى سطر جديد داخل النص.

Hello<br>
World

8. الخط الأفقي hr

يُستخدم لإنشاء فاصل موضوعي أفقي بين المحتويات.

<p>First section</p>
<hr>
<p>Second section</p>

9. التنسيق النصي

تُستخدم هذه الوسوم لإعطاء النص دلالات أو تنسيقات مختلفة.

<b>Bold text</b>

<strong>Important text</strong>

<i>Italic text</i>

<em>Emphasized text</em>

<u>Underlined text</u>

<mark>Highlighted text</mark>

<del>Deleted text</del>

<small>Small text</small>

<sub>Subscript</sub>

<sup>Superscript</sup>

10. التعليقات Comments

تُستخدم لكتابة ملاحظات داخل الكود لا تظهر في المتصفح.

<!-- This is a comment -->

03 - الروابط والصور والوسائط

11. الروابط Links

يُستخدم وسم a لإنشاء رابط ينقل المستخدم إلى صفحة أو موقع آخر، وتحدد الخاصية href وجهة الرابط. 

<a href="https://google.com">
    Visit Google
</a>

<a href="about.html">
    About Us
</a>

12. الصور Images

يُستخدم img لإضافة صورة، وتحدد src مسار الصورة، بينما توفر alt وصفاً بديلاً لها. 

<img src="image.jpg"
     alt="Description"
     width="300">

13. الفيديو Video

يُستخدم لإضافة مقطع فيديو داخل الصفحة.

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
    Your browser does not support video.
</video>

14. الصوت Audio

يُستخدم لإضافة ملف صوتي إلى الصفحة.

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

15. iframe

يسمح بعرض صفحة ويب أو محتوى خارجي داخل إطار ضمن الصفحة. 

<iframe
    src="https://example.com"
    width="400"
    height="250"
    title="Example">
</iframe>

04 - القوائم Lists

16. القائمة غير المرتبة ul

تنشئ قائمة بعناصر تظهر عادة على شكل نقاط.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

17. القائمة المرتبة ol

تنشئ قائمة مرقمة حسب ترتيب العناصر.

<ol>
    <li>First</li>
    <li>Second</li>
    <li>Third</li>
</ol>

18. القوائم الوصفية dl

تُستخدم لعرض مصطلح مع وصفه.

<dl>
    <dt>HTML</dt>
    <dd>Markup Language</dd>

    <dt>CSS</dt>
    <dd>Style Language</dd>
</dl>

05 - الجداول Tables

19. إنشاء جدول table

يُستخدم لإنشاء جدول يحتوي على صفوف وأعمدة.

<table border="1">

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Ahmed</td>
        <td>20</td>
    </tr>

</table>
table: الجدول - tr: الصف - th: خلية عنوان - td: خلية بيانات.

20. دمج الخلايا colspan و rowspan

تسمح بدمج الخلايا أفقياً أو عمودياً.

<table border="1">
    <tr>
        <th colspan="2">Students</th>
    </tr>

    <tr>
        <td rowspan="2">Ali</td>
        <td>20</td>
    </tr>

    <tr>
        <td>21</td>
    </tr>
</table>

06 - النماذج Forms

21. وسم form

يُستخدم لإنشاء نموذج يسمح للمستخدم بإدخال البيانات وإرسالها.

<form action="submit.php" method="post">

    <label for="name">Name:</label>

    <input type="text" id="name" name="name">

    <button type="submit">Send</button>

</form>

22. وسم input

يُستخدم لإنشاء حقول إدخال مختلفة حسب قيمة الخاصية type.

<input type="text">
<input type="password">
<input type="email">
<input type="number">
<input type="date">
<input type="time">
<input type="checkbox">
<input type="radio">
<input type="file">
<input type="color">
<input type="range">
<input type="submit">
<input type="reset">

23. وسم label

يُستخدم لإضافة تسمية توضح وظيفة حقل الإدخال.

<label for="email">Email:</label>

<input type="email" id="email">

24. وسم textarea

يُستخدم لإنشاء مساحة لإدخال نصوص طويلة.

<textarea rows="5" cols="30">
Write here...
</textarea>

25. وسم select و option

يُستخدم لإنشاء قائمة منسدلة تحتوي على عدة خيارات.

<select>
    <option>HTML</option>
    <option>CSS</option>
    <option>JavaScript</option>
</select>

26. وسم button

يُستخدم لإنشاء زر قابل للتفاعل.

<button type="button">
    Click Me
</button>

07 - تنظيم الصفحة Semantic HTML

27. وسم header

يمثل مقدمة الصفحة أو مقدمة قسم معين.

<header>
    <h1>My Website</h1>
</header>

28. وسم nav

يحتوي على روابط التنقل الرئيسية.

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
</nav>

29. وسم main

يمثل المحتوى الرئيسي والفريد للصفحة.

<main>
    <h1>Main Content</h1>
</main>

30. وسم section

يُستخدم لتقسيم الصفحة إلى أقسام موضوعية.

<section>
    <h2>About Us</h2>
    <p>Our information</p>
</section>

31. وسم article

يمثل محتوى مستقلاً مثل مقال أو منشور.

<article>
    <h2>Article Title</h2>
    <p>Article content</p>
</article>

32. وسم aside

يمثل محتوى جانبياً مرتبطاً بالمحتوى الرئيسي.

<aside>
    Related Information
</aside>

33. وسم footer

يمثل تذييل الصفحة أو القسم، ويحتوي غالباً على معلومات الحقوق والتواصل.

<footer>
    <p>Copyright 2026</p>
</footer>

08 - العناصر العامة

34. وسم div

عنصر عام يُستخدم لتجميع وتنظيم مجموعة من العناصر.

<div class="container">
    <h2>Title</h2>
    <p>Description</p>
</div>

35. وسم span

عنصر عام داخل السطر يُستخدم لتحديد جزء صغير من النص.

<p>
    Learn <span>HTML</span> today.
</p>

36. وسم details و summary

يُستخدم لإنشاء محتوى يمكن فتحه وإغلاقه دون JavaScript.

<details>
    <summary>What is HTML?</summary>
    <p>HTML is a markup language.</p>
</details>

09 - أهم خصائص HTML Attributes

37. خاصية id

تعطي العنصر معرفاً فريداً يمكن استخدامه في CSS وJavaScript.

<h1 id="title">Hello</h1>

38. خاصية class

تُستخدم لتجميع العناصر التي تشترك في نفس التنسيق أو السلوك.

<p class="description">
    Welcome
</p>

39. خاصية style

تسمح بإضافة تنسيقات CSS مباشرة إلى العنصر.

<p style="color: blue;">
    Blue Text
</p>

40. خصائص عامة أخرى

تُستخدم للتحكم في سلوك العناصر أو توفير معلومات إضافية.

<input required>

<input disabled>

<input readonly>

<input placeholder="Enter name">

<input value="Ahmed">

<button title="Click here">Click</button>

<p hidden>Hidden content</p>

10 - ربط HTML مع CSS و JavaScript

41. ربط ملف CSS

تُستخدم link لربط صفحة HTML بملف CSS خارجي.

<head>
    <link rel="stylesheet" href="style.css">
</head>

42. ربط ملف JavaScript

يُستخدم script لربط ملف JavaScript بالصفحة.

<body>

    <script src="script.js"></script>

</body>

الخلاصة

HTML هي الأساس في بناء صفحات الويب. تعلم هذه الوسوم والخصائص جيداً، ثم انتقل إلى CSS لتنسيق الصفحات وJavaScript لإضافة التفاعلية والوظائف.
