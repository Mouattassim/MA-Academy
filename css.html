تعلم CSS من الصفر

تعلم تنسيق صفحات الويب خطوة بخطوة، من أساسيات الألوان والخطوط إلى Flexbox وGrid والتصميم المتجاوب والحركات.

01

ما هي CSS؟

CSS اختصار لـ Cascading Style Sheets، وهي اللغة المسؤولة عن تنسيق صفحات HTML والتحكم في الألوان والخطوط والمسافات والتخطيط.

معلومة: HTML تبني هيكل الصفحة، وCSS تمنحها الشكل والتصميم.
02

طرق إضافة CSS

يمكن إضافة CSS بثلاث طرق: ملف خارجي، أو وسم style داخل head، أو خاصية style داخل العنصر. يُفضّل استخدام الملف الخارجي لتنظيم المشروع.

styles.css
/* داخل ملف styles.css */
h1 {
  color: blue;
}

/* أو داخل head:
<style>
  h1 { color: blue; }
</style>
*/

/* أو داخل العنصر:
<h1 style="color: blue;">مرحبا</h1>
*/
الطريقة الخارجية تجعل التنسيق قابلًا لإعادة الاستخدام في صفحات متعددة.
03

ربط ملف CSS بصفحة HTML

أنشئ ملفًا باسم style.css بجانب ملف HTML، ثم اربطه داخل عنصر head باستخدام link.

index.html + style.css
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>أهلاً بك</h1>
</body>
</html>
تأكد من كتابة المسار الصحيح لملف CSS.
04

بنية قاعدة CSS

تتكوّن قاعدة CSS من محدد selector، ثم أقواس تحتوي على خصائص properties وقيم values.

style.css
h1 {
  color: blue;
  font-size: 32px;
}
كل تصريح ينتهي بفاصلة منقوطة ;
05

المحددات Selectors

تحدد المحددات عناصر HTML التي نريد تنسيقها. يمكن اختيار العنصر باسمه أو class أو id.

style.css
/* محدد العنصر */
p {
  color: #444;
}

/* محدد class */
.card {
  padding: 20px;
}

/* محدد id */
#header {
  background: navy;
}
استخدم class عندما تريد تطبيق نفس التنسيق على عدة عناصر.
06

محددات متعددة ومتداخلة

يمكن تنسيق عدة محددات معًا بالفاصلة، كما يمكن استهداف عنصر داخل عنصر آخر بترك مسافة بين المحددات.

selectors.css
h1, h2, h3 {
  font-family: Arial, sans-serif;
}

.card p {
  color: #555;
}
الفاصلة تعني نفس التنسيق لكل المحددات، والمسافة تعني عنصرًا داخل عنصر.
07

الألوان Color

تقبل CSS أسماء الألوان، وHex، وRGB، وRGBA، وHSL. اختر صيغة تناسب نظام ألوان مشروعك.

colors.css
h1 {
  color: #0066ff;
}

.box {
  background-color: rgb(20, 80, 180);
  border-color: rgba(0, 0, 0, 0.2);
}
RGBA تسمح بتحديد درجة الشفافية.
08

الخلفيات Backgrounds

تستطيع التحكم في لون الخلفية أو وضع صورة وتحديد طريقة تكرارها وحجمها وموقعها.

background.css
body {
  background-color: #f4f7ff;
}

.hero {
  background-image: url("images/cover.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
استخدم cover عندما تريد أن تغطي الصورة مساحة العنصر كاملة.
09

الخطوط Font Family

تحدد font-family نوع الخط. اكتب أكثر من خيار احتياطي، حتى ينتقل المتصفح إلى الخط التالي إذا لم يتوفر الأول.

fonts.css
body {
  font-family: Arial, Helvetica, sans-serif;
}

h1 {
  font-family: Georgia, serif;
}
ضع نوعًا عامًا مثل sans-serif في نهاية القائمة.
10

حجم ووزن النص

تتحكم font-size في حجم النص، وfont-weight في سماكته، وfont-style في نمطه.

text.css
h1 {
  font-size: 36px;
  font-weight: 700;
}

p {
  font-size: 16px;
  font-style: normal;
}
يمكن استعمال قيم مثل 400 للعادي و700 للعريض.
11

محاذاة النص وارتفاع السطر

تستخدم text-align للمحاذاة، وline-height للمسافة الرأسية بين الأسطر، وletter-spacing للمسافة بين الحروف.

text-align.css
p {
  text-align: right;
  line-height: 1.8;
  letter-spacing: 0;
}

.center {
  text-align: center;
}
للقراءة المريحة، لا تجعل ارتفاع السطر ضيقًا جدًا.
12

الوحدات Units

من الوحدات الشائعة px و% وem وrem وvw وvh. بعضها ثابت وبعضها نسبي لحجم الخط أو الشاشة أو العنصر الأب.

units.css
html {
  font-size: 16px;
}

.box {
  width: 80%;
  padding: 1rem;
  min-height: 50vh;
}
rem يعتمد على حجم الخط الأساسي في الصفحة، وغالبًا يسهل توحيد المقاسات به.
13

العرض والارتفاع

تحدد width وheight أبعاد العنصر، ويمكن استخدام min-width وmax-width وmin-height وmax-height لوضع حدود مرنة.

sizing.css
.container {
  width: 90%;
  max-width: 1100px;
  min-height: 300px;
  margin: auto;
}
max-width مفيد لمنع المحتوى من التمدد أكثر من اللازم.
14

نموذج الصندوق Box Model

كل عنصر يتكون من content ثم padding ثم border ثم margin. فهم هذه الطبقات ضروري للتحكم في المسافات والأبعاد.

box-model.css
* {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #ddd;
  margin: 16px;
}
استخدم box-sizing: border-box لتصبح حسابات العرض أسهل.
15

الهوامش Margin

تضيف margin مساحة خارج حدود العنصر، ويمكن تحديدها لكل جهة أو استخدام قيمة auto لتوسيط عنصر ذي عرض محدد.

margin.css
.container {
  width: 80%;
  margin: 0 auto;
}

.card {
  margin-top: 20px;
  margin-bottom: 12px;
}
margin لا تضيف مساحة داخل العنصر؛ هذه وظيفة padding.
16

الحشو Padding

تضيف padding مساحة بين المحتوى وحدود العنصر. يمكن ضبط الجهات الأربع بقيمة واحدة أو بقيم منفصلة.

padding.css
.button {
  padding: 12px 24px;
}

.card {
  padding-top: 20px;
  padding-right: 16px;
  padding-bottom: 20px;
  padding-left: 16px;
}
زيادة padding تجعل المساحة الداخلية أكبر.
17

الحدود Border

تتحكم border في سمك الحد ونمطه ولونه، ويمكن تخصيص كل جهة على حدة.

border.css
.card {
  border: 1px solid #dbe3f0;
  border-top: 4px solid #087cff;
}
من الأنماط الشائعة solid وdashed وdotted وnone.
18

الزوايا الدائرية Border Radius

تستخدم border-radius لتدوير زوايا العناصر. يمكن تطبيقها على جميع الزوايا أو تخصيص كل زاوية.

radius.css
button {
  border-radius: 12px;
}

.avatar {
  width: 80px;
  height: 80px;
  border-radius: 50%;
}
القيمة 50% تجعل العنصر مربعًا دائريًا إذا تساوى العرض والارتفاع.
19

الظلال Box Shadow

تضيف box-shadow ظلًا حول العنصر، وتحدد الإزاحة الأفقية والرأسية والتمويه والانتشار واللون.

shadow.css
.card {
  box-shadow: 0 8px 24px rgba(0, 40, 100, 0.12);
}
اجعل الظل خفيفًا حتى لا يشتت الانتباه عن المحتوى.
20

الشفافية Opacity

تحدد opacity شفافية العنصر كاملًا، من 0 غير مرئي إلى 1 معتم بالكامل.

opacity.css
 .muted {
  opacity: 0.6;
}

.overlay {
  background: rgba(0, 0, 0, 0.45);
}
إذا أردت شفافية الخلفية فقط دون النص، استخدم لونًا بصيغة rgba.
21

العرض inline وblock

العنصر block يبدأ عادة بسطر جديد ويأخذ العرض المتاح، بينما inline يبقى ضمن السطر. inline-block يجمع بعض خصائص الاثنين.

display.css
.block {
  display: block;
}

.inline {
  display: inline;
}

.inline-box {
  display: inline-block;
}
يمكن تغيير سلوك العرض باستخدام display.
22

إخفاء العناصر

يمكن إخفاء عنصر باستخدام display: none أو visibility: hidden. الأول يزيل مكانه من التخطيط، والثاني يخفيه مع بقاء المساحة.

visibility.css
.hidden-completely {
  display: none;
}

.hidden-but-space-remains {
  visibility: hidden;
}
اختر الطريقة حسب ما إذا كنت تريد الاحتفاظ بمكان العنصر أم لا.
23

التموضع Position

تحدد position طريقة تموضع العنصر: static أو relative أو absolute أو fixed أو sticky. ويمكن تحريكه باستخدام top وright وbottom وleft.

position.css
 .parent {
  position: relative;
}

.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}

.navbar {
  position: sticky;
  top: 0;
}
absolute يتموضع نسبةً إلى أقرب سلف له position غير static.
24

ترتيب الطبقات z-index

تتحكم z-index في ترتيب العناصر المتداخلة؛ القيمة الأعلى تظهر عادة فوق القيمة الأقل ضمن سياق التكديس نفسه.

z-index.css
 .menu {
  position: relative;
  z-index: 10;
}

.backdrop {
  position: fixed;
  inset: 0;
  z-index: 5;
}
z-index لا يعمل كما تتوقع دون فهم position وسياقات التكديس.
25

Flexbox: البداية

Flexbox نظام تخطيط أحادي البعد لترتيب العناصر في صف أو عمود. فعّل display: flex على العنصر الأب.

flex.css
 .container {
  display: flex;
  flex-direction: row;
  gap: 16px;
}
العنصر الذي يحمل display:flex يسمى flex container.
26

Flexbox: المحاذاة والتوزيع

تستخدم justify-content لتوزيع العناصر على المحور الرئيسي، وalign-items لمحاذاتها على المحور العرضي.

flex-align.css
 .container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  min-height: 200px;
}
غيّر flex-direction لتعرف كيف يتغير المحور الرئيسي.
27

Flexbox: الالتفاف والنمو

تسمح flex-wrap بانتقال العناصر إلى سطر جديد، وتتحكم flex-grow وflex-shrink وflex-basis في أحجام العناصر المرنة.

flex-wrap.css
 .container {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.item {
  flex: 1 1 220px;
}
gap يضيف مسافة منتظمة بين العناصر دون الحاجة إلى margins.
28

CSS Grid: البداية

CSS Grid نظام تخطيط ثنائي الأبعاد يتيح التحكم في الصفوف والأعمدة معًا. فعّل display: grid على الحاوية.

grid.css
 .grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 20px;
}
Grid مناسب لتخطيطات البطاقات والأقسام متعددة الأعمدة.
29

Grid: أعمدة مرنة

يمكن استخدام repeat وminmax لإنشاء أعمدة تتكيف مع المساحة المتاحة بدل تثبيت عدد الأعمدة يدويًا.

grid-responsive.css
 .cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 18px;
}
auto-fit مع minmax مفيد لشبكات البطاقات المتجاوبة.
30

التصميم المتجاوب Responsive Design

يجعل التصميم المتجاوب الصفحة مناسبة للهواتف والأجهزة اللوحية والشاشات الكبيرة باستخدام وحدات مرنة وصور مناسبة وMedia Queries.

responsive.css
img {
  max-width: 100%;
  height: auto;
}

.container {
  width: min(92%, 1100px);
  margin-inline: auto;
}
ابدأ بتصميم بسيط للشاشات الصغيرة ثم وسّعه للشاشات الأكبر عند الحاجة.
31

Media Queries

تسمح @media بتطبيق قواعد CSS عند تحقق شرط مثل عرض الشاشة. تُستخدم كثيرًا لتغيير الأعمدة وحجم الخط والقوائم.

media.css
/* على الشاشات الصغيرة */
@media (max-width: 700px) {
  .cards {
    grid-template-columns: 1fr;
  }

  h1 {
    font-size: 28px;
  }
}
نقطة التوقف ليست رقمًا سحريًا؛ اخترها عندما يحتاج التصميم إلى التغيير.
32

الحالات Hover وFocus وActive

تسمح pseudo-classes بتنسيق العنصر حسب حالته، مثل hover عند مرور المؤشر وfocus عند التركيز وactive أثناء الضغط.

states.css
button:hover {
  background: #005bd1;
}

input:focus {
  outline: 2px solid #087cff;
}

button:active {
  transform: scale(0.98);
}
لا تعتمد على hover وحده؛ يجب أن تكون الواجهة قابلة للاستخدام بلوحة المفاتيح أيضًا.
33

العناصر الزائفة Before وAfter

تضيف ::before و::after محتوى زخرفيًا قبل محتوى العنصر أو بعده. غالبًا تحتاج إلى خاصية content.

pseudo-elements.css
.title::after {
  content: "";
  display: block;
  width: 60px;
  height: 4px;
  margin-top: 8px;
  background: #087cff;
}
استخدمها للزخرفة والمؤشرات، وليس للمعلومات الأساسية التي يجب أن يقرأها الجميع.
34

الانتقالات Transitions

تجعل transition تغيرات الخصائص أكثر سلاسة، مثل تغير اللون أو الحجم عند hover.

transition.css
button {
  background: #087cff;
  transition: background 0.25s ease,
              transform 0.25s ease;
}

button:hover {
  background: #005bd1;
  transform: translateY(-2px);
}
حدد الخصائص التي تريد انتقالها بدل استخدام all دون حاجة.
35

التحويلات Transforms

تسمح transform بتحريك العنصر أو تدويره أو تكبيره أو إمالته دون تغيير تدفق الصفحة.

transform.css
 .card:hover {
  transform: translateY(-6px) scale(1.02);
}

.icon {
  transform: rotate(15deg);
}
يمكن جمع أكثر من تحويل في الخاصية نفسها.
36

Animations و Keyframes

تستخدم @keyframes لتعريف مراحل الحركة، ثم animation لتشغيلها وتحديد مدتها وتكرارها.

animation.css
@keyframes appear {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.card {
  animation: appear 0.6s ease both;
}
استعمل الحركة باعتدال، وراعِ إعداد prefers-reduced-motion للمستخدمين الذين يفضلون تقليل الحركة.
37

المتغيرات CSS Variables

تُعرّف المتغيرات باستخدام --name وتُستدعى عبر var(). غالبًا توضع في :root لتكون متاحة على مستوى الصفحة.

variables.css
 :root {
  --primary: #087cff;
  --text: #172033;
  --radius: 14px;
}

button {
  background: var(--primary);
  border-radius: var(--radius);
}
المتغيرات تسهّل تغيير ألوان الموقع وأحجامه من مكان واحد.
38

الدوال calc و min و max و clamp

تساعد دوال CSS على حساب الأحجام بمرونة. calc تنفذ عملية حسابية، وmin وmax تختاران قيمة، وclamp تحدد حدًا أدنى ومرنًا وأقصى.

functions.css
 .container {
  width: min(92%, 1200px);
}

h1 {
  font-size: clamp(2rem, 5vw, 4rem);
}

.panel {
  width: calc(100% - 32px);
}
clamp ممتازة لحجم الخط المتجاوب دون عدد كبير من Media Queries.
39

القوائم والجداول

يمكن تنسيق القوائم باستخدام list-style، والجداول باستخدام border-collapse وpadding وحدود الخلايا.

lists-tables.css
ul {
  list-style: square;
  padding-inline-start: 24px;
}

table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  padding: 12px;
  border: 1px solid #ddd;
}
احرص على وضوح تباين النص والخلفية في الجداول.
40

تنسيق الصور والفيديو

استخدم object-fit للتحكم في كيفية ملء الصورة أو الفيديو للمساحة، وobject-position لتحديد الجزء الظاهر.

media-elements.css
 .thumbnail {
  width: 100%;
  height: 220px;
  object-fit: cover;
  object-position: center;
}
cover يملأ المساحة وقد يقص جزءًا من الصورة، بينما contain يعرض الصورة كاملة.
41

تنسيق النماذج Forms

يمكن تنسيق input وtextarea وselect وbutton مثل بقية العناصر، مع الاهتمام بحالة focus وحجم مساحة اللمس.

forms.css
input, textarea, select {
  width: 100%;
  padding: 12px;
  border: 1px solid #ccd5e2;
  border-radius: 8px;
  font: inherit;
}

input:focus {
  outline: 2px solid #087cff;
}
لا تحذف outline دون توفير مؤشر تركيز بديل واضح.
42

الطبقات الشفافة والتدرجات

تسمح linear-gradient وradial-gradient بإنشاء خلفيات متدرجة، ويمكن دمج التدرج مع صورة خلفية لصنع طبقة لونية.

gradients.css
 .hero {
  background:
    linear-gradient(120deg,
      rgba(0, 60, 180, 0.9),
      rgba(0, 160, 255, 0.55)),
    url("cover.jpg") center/cover;
}
يمكن استخدام التدرج بدل صورة خلفية بسيطة في كثير من الواجهات.
43

تنظيم CSS وأفضل الممارسات

قسّم التنسيقات إلى أقسام واضحة، واستخدم أسماء classes مفهومة، وتجنب تكرار القواعد ورفع specificity دون حاجة.

organized.css
/* 1. إعدادات عامة */
* {
  box-sizing: border-box;
}

/* 2. عناصر الصفحة */
body {
  margin: 0;
}

/* 3. المكونات */
.card {
  padding: 1rem;
}

/* 4. الاستجابة */
@media (max-width: 700px) {
  .card {
    padding: 0.75rem;
  }
}
التنسيق الجيد يسهل صيانة المشروع وتطويره لاحقًا.
44

Specificity وأولوية القواعد

عند تعارض القواعد، تؤثر أولوية المحددات ومصدر القاعدة وترتيبها و!important. تجنب استعمال !important كحل دائم.

specificity.css
p {
  color: gray;
}

.note {
  color: blue;
}

#warning {
  color: red;
}

/* تجنب الإكثار من !important */
المحدد id أعلى specificity من class، ومحدد العنصر أقل منهما.
45

الوراثة والقيم الافتراضية

بعض خصائص CSS مثل color وfont-family تُورّث غالبًا من العنصر الأب، بينما خصائص مثل margin لا تُورّث عادة.

inheritance.css
body {
  color: #202938;
  font-family: Arial, sans-serif;
}

button {
  font: inherit;
  color: inherit;
}
يمكن استعمال inherit أو initial أو unset للتحكم في قيمة الخاصية.
46

الطباعة Print Styles

تتيح @media print تجهيز الصفحة للطباعة، مثل إخفاء الأزرار والقوائم وتغيير الألوان والخلفيات.

print.css
@media print {
  nav, button, .no-print {
    display: none;
  }

  body {
    color: #000;
    background: #fff;
  }
}
اختبر معاينة الطباعة للتأكد من أن المحتوى المهم ظاهر.
47

إتاحة الوصول وتقليل الحركة

اجعل التباين واضحًا، وأظهر مؤشر التركيز، ولا تستخدم اللون وحده لنقل المعنى. احترم تفضيل تقليل الحركة.

accessibility.css
:focus-visible {
  outline: 3px solid #087cff;
  outline-offset: 3px;
}

@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
التصميم الجيد يجب أن يكون مفهومًا وقابلًا للاستخدام بطرق مختلفة.
48

مشروع تطبيقي: بطاقة شخصية

اجمع ما تعلمته لإنشاء بطاقة شخصية تحتوي على صورة واسم ووصف وزر. ابدأ ببنية HTML ثم اربط ملف CSS.

profile-card.css
* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  display: grid;
  place-items: center;
  background: #eef4ff;
  font-family: Arial, sans-serif;
}

.profile {
  width: min(90%, 320px);
  padding: 24px;
  text-align: center;
  background: white;
  border-radius: 18px;
  box-shadow: 0 10px 30px #163b7020;
}

.profile img {
  width: 100px;
  height: 100px;
  border-radius: 50%;
  object-fit: cover;
}

.profile button {
  padding: 10px 20px;
  color: white;
  background: #087cff;
  border: 0;
  border-radius: 8px;
}
جرّب تغيير الألوان والمسافات والزوايا بنفسك.
لا توجد دروس مطابقة لبحثك.

مشروعك الأول

بعد إنهاء الدروس، جرّب إنشاء صفحة تعريفية بسيطة تحتوي على عنوان رئيسي، وفقرة عنك، وصورة، ورابط، وقائمة بالمهارات التي تتعلمها. لا تنتقل إلى CSS قبل أن تفهم هيكل HTML جيدًا.
